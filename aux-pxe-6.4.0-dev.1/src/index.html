THREE INDEPENDENT COMMANDS

Download, deploy, generate.

Download command bundle ↓

Download from light-url.txt or heavy-url.txt, deploy light resources to RAM and heavy resources to disk, then crawl the published units to generate both catalogs, the iPXE menu and sitemaps. Each script contains its own task implementation, with shared settings in fast-boot.json.

Explicit RAM copy

For Excalibur: select light-url.txt, copy cached netinstall and tool images into tmpfs, publish symbolic links and mount their contents read-only. Check available memory before deployment. The generator adds links to prepared contents.

NETWORK BOOT

Start with iPXE.

Deploy the files and generate the menu on the mirror first. These commands load the menu hosted at the configured boot server.

Start an x86_64 UEFI iPXE client

Use an iPXE EFI build with the network driver and HTTP support for the target machine. Then enter the following commands at its prompt.

dhcp
chain @@PXE_URL@@/menu.ipxe

Secure Boot needs a trusted, signed boot chain. Boot recipes are checked for local files; hardware and firmware boot tests remain separate.
