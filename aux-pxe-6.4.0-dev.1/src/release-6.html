Two terminals in a new browser tab

Open terminal from CLI or the case register to open Terminal 1 and Terminal 2. Each has Paste and Ctrl+C controls. Switching tabs keeps both shells connected. Update TEC, CLI and the Live client together.

WAN Arsenal and local USB networking

WAN Arsenal names the iPXE menu. Local persistent and RAM boots obtain their own connection and DNS through NetworkManager. The menu remains available offline.

Llave y asistencia

La primera entrada USB persistente arranca tras 5 segundos. El caso autorizado puede continuar durante ocho horas en el mismo equipo, por web o SSH 4242. Reiniciar abre una shell nueva. Kit portable.

Hacer, revisar y deshacer

G y M abren los agentes sin root en F4/F5. Ambos usan el mismo ejecutor local. E en F6 muestra plan, ID, SHA-256 y estado previo. Simular no modifica el destino. Aplicar y deshacer requieren frases distintas de confirmación. I cierra ambas API.

No hay shell arbitraria. Las propuestas caducan y el canal del agente no admite aprobar ni ejecutar. El diario y las copias son privados y efímeros: no hay deshacer tras reiniciar. Los resultados solo salen hacia la API al escribir ENVIAR.

Servicios por ubicación

Excalibur ejecuta aux-cli, Nginx y TEC/PHP. La ISO contiene aux-gpt, aux-gemini y aux-exec. Las API se consultan directamente por HTTPS, con entrada de clave visible u oculta; cli.1-s.es sigue siendo la pasarela SSH humana, no una pasarela API de IA.

Las sesiones API son nuevas y no heredan esta conversación. Hola mundo allí no envía un mensaje a este chat. No se incluyen claves ni un modelo supuestamente universal.

Bastion: una sola raíz B/P/T

Los tres dominios usan la misma carpeta OVH con el despliegue entero, las ISO, árboles, catálogo y TEC público. assemble.py materializa enlaces autorizados como archivos físicos. Datos privados y secretos quedan fuera. Bastion no ejecuta CLI; Kamala es alternativo manual.
