DISTRIBUCIÓN MODULAR · 8.0.1-beta.3

Elegir los módulos.
Montar la web.

AUX/PXE y TEC/CLI se distribuyen por separado. Cada grupo puede instalar los servicios que necesita, en un mismo equipo o en servidores distintos.

AUX toma su nombre de María Auxiliadora.

Dos módulos independientes

01 / CATÁLOGO Y NETBOOT

aux-pxe

Portal gráfico, catálogo ISO para Links, guías de comandos, iPXE y herramientas de instalación y rescate.

Funciona sin instalar TEC/CLI. Python y Bash para generar; la web resultante es estática y puede publicarse por FTPS.

Paquete no alojado en esta réplica · ZIP · 8.0.1-beta.3

python3 install-web.py --modules aux-pxe
02 / COMUNIDAD Y ASISTENCIA

tec-cli

Cuentas TEC, asistencia, registro privado, terminal web y foro de recetas con lectura y formularios para Links.

PHP y gateway Python en un servidor propio. El foro nativo reutiliza las cuentas TEC y guarda JSON privado; no necesita Sites, Node ni D1.

Paquete no alojado en esta réplica · ZIP · 8.0.1-beta.3

python3 install-web.py --modules tec-cli

Suite completa

Los dos módulos, las herramientas AUX, osquery/osctrl configurables, ayuda F1 y documentación de las tareas.

8.0.1-beta.3 · Paquete no alojado en esta réplica · TAR.GZ

SHA-256 local: Consultar el archivo SHA-256 del paquete recibido.

Los paquetes no incluyen ISO de distribuciones, cuentas, datos del foro, credenciales ni el servidor osctrl.

Revisar el plan antes de instalar

Extraer cada ZIP en un directorio vacío. Para ambos módulos, se pueden extraer juntos o utilizar la suite completa. Los comandos siguientes muestran un plan y no modifican el sistema.

python3 install-web.py --modules aux-pxe
python3 install-web.py --modules tec-cli
python3 install-web.py --modules aux-pxe tec-cli

Revisar rutas, dependencias y TLS antes de añadir --apply. La opción --nginx configura únicamente los vhosts seleccionados y comprueba los conflictos existentes.
