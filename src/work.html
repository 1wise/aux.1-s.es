La ISO fija AUX Rescue incluye una unidad tmpfs privada de root. Sirve para herramientas, descargas temporales, informes y preparar un chroot. Su capacidad es un límite, no una reserva: solo consume memoria según se escriben archivos. Comparte RAM con el sistema Live y su overlay.

Límite
El menor entre RAM total / 4, RAM disponible / 3 y 2 GiB.
Permisos
0700, root. Opciones nosuid y nodev. Se permite ejecutar herramientas.
Duración
El contenido se pierde al reiniciar o apagar. Guardar fuera los informes que deban conservarse.
Memoria insuficiente
Si el límite resulta inferior a 64 MiB, el servicio falla con un diagnóstico; no utiliza un disco del cliente como sustituto.

La imagen no activa swap de los discos del cliente. El siguiente código es la fuente versionada de la receta 5.0.1-dev.5, conservada también en la ISO fija. No necesita una aplicación pesada.
