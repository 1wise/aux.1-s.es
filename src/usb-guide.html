Crear la llave USB: Fedora, Debian/Ubuntu, Windows y macOS

Dos imágenes distintas: aux-ipxe-usb.img es la llave pequeña que obtiene menu.ipxe por red; aux-rescue-…iso contiene el sistema Live. Grabar la imagen completa sobre el dispositivo USB. Copiar el archivo al explorador no crea la llave. La escritura reemplaza el contenido del USB: comprobar modelo, capacidad y dispositivo.

La llave actual arranca en BIOS o UEFI x86_64; su cargador UEFI no está firmado para Secure Boot. No es una llave ARM64 ni un medio de arranque para Apple Silicon. Crear la llave en un Mac no cambia su arquitectura.

1. Descargar y verificar

Usar la imagen y su SHA256SUMS de la misma publicación. Fuentes y compilación de la llave. Para AUX Rescue, la ISO debe compilarse y medirse primero: el manifiesto de receta no sustituye su checksum.

Fedora

sudo dnf install mediawriter
sha256sum aux-ipxe-usb.img
lsblk -o NAME,SIZE,MODEL,TRAN,MOUNTPOINTS

En Fedora Media Writer elegir imagen personalizada, seleccionar la imagen y verificar el USB de destino. Comparar el hash calculado con el publicado antes de grabar.

Debian y Ubuntu

sudo apt update
sudo apt install gnome-disk-utility
sha256sum aux-ipxe-usb.img
lsblk -o NAME,SIZE,MODEL,TRAN,MOUNTPOINTS

En Discos seleccionar el dispositivo USB, abrir «Restaurar imagen de disco» y elegir la imagen. Revisar el dispositivo y confirmar. No usar la operación sobre el disco del sistema.

Alternativa de terminal Linux

Después de identificar el dispositivo completo y desmontar sus particiones montadas. El marcador siguiente debe reemplazarse; no usar una partición como /dev/sdb1.

arc_img="$PWD/aux-ipxe-usb.img"
dev_usb=/dev/REEMPLAZAR_USB
lsblk -o NAME,SIZE,MODEL,TRAN,MOUNTPOINTS "$dev_usb"
# Run only after confirming and unmounting the selected USB partitions.
sudo dd if="$arc_img" of="$dev_usb" bs=4M status=progress conv=fsync
sync

Windows

Usar Rufus oficial o Fedora Media Writer. Seleccionar la imagen y comprobar el USB. Si Rufus pregunta por modo ISO o DD, elegir DD para conservar la imagen híbrida tal como se construyó.

Get-FileHash .ux-ipxe-usb.img -Algorithm SHA256

El comando anterior se ejecuta en PowerShell. Tras grabar, rechazar cualquier solicitud de Windows de formatear particiones Linux.

macOS

Fedora Media Writer permite seleccionar una imagen personalizada. Alternativa de terminal:

shasum -a 256 aux-ipxe-usb.img
diskutil list

Identificar el USB completo. Reemplazar N por su número real, nunca elegir el disco del sistema:

diskutil unmountDisk /dev/diskN
sudo dd if=aux-ipxe-usb.img of=/dev/rdiskN bs=4m
sync
diskutil eject /dev/diskN

Durante dd, Ctrl+T permite consultar el progreso en macOS. Para una ISO híbrida, sustituir únicamente el archivo de entrada por el nombre de la ISO verificada.

Prueba de la llave

Elegir el USB en el menú de arranque del equipo. La llave iPXE debe mostrar GRUB durante 5 segundos, obtener red y cargar menu.ipxe; el menú de asistencia tiene su temporizador independiente de 60 segundos. Primero probar la llave sin realizar ninguna operación sobre discos. La escritura en los cuatro sistemas no se ha probado físicamente en esta publicación.
